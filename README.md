# The Outer Loop

A living dossier of engineers who publish **how they actually collaborate with coding agents**.

The archetype is [Lauren Tan](https://x.com/poteto): Principal Engineer on Grok Bot and Cursor at SpaceXAI, React Core (React Compiler), formerly Meta and Netflix. She open-sourced [pstack](https://cursor.com/marketplace/cursor/pstack) after her team used those skills 10,000 times in a week.

This repo is not an influencer list. It is a research file: super bios, titles, core lessons on AI collab and reasoning, and the skills/repos they shipped.

## Run locally


```bash

```

## Stack

Next.js, TypeScript, Tailwind, shadcn/ui. Content lives in `src/data/` so a new engineer is a typed object, not a CMS.

## Iterate

The brief was to keep going until asked to stop. Add a person when they publish a **method** (skill pack, loop, spec ritual, eval), not when they trend.
